Command Overview

Navigation

  • h j k l Move cursor
  • w e b Word selection
  • 0 $ Start / End of Line
  • g g Start of File
  • G End of File

Editing

  • i a Insert / Append
  • o O Open new line
  • d w Delete word
  • c i w Change inner word
  • u Undo

Design Boundaries

Due to iframe security in Google Docs, Yanking / Pasting (y, p) and Search (/, ?, n, N) commands act as short-circuits. They will safely abort any ongoing operations and display a toast guiding you to use native system shortcuts like Ctrl+C / Ctrl+V or Ctrl+F / Ctrl+G.
